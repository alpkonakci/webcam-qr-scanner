# Webcam QR Scanner v0.2.0-beta.5

Create QR codes on Windows and read saved or pasted QR images on your phone.
This is a Windows x64 / Phone-to-PC pre-release; the latest stable is v0.1.1.

## What's new

- **Create QR** in the desktop home screen and tray: enter a link or short text,
  preview the code, **Save PNG** or **Copy QR**. Turkish characters, emoji and
  multiple lines are supported. Creation works offline.
- For videos, GIFs and PDFs, use the file's existing sharing link. The app does
  not host files. Content is limited to 600 UTF-8 bytes for readable QR codes.
- **Read from image** on the phone: **Choose image** or **Paste image** scans a
  PNG, JPEG or WebP automatically. Images stay on the device. Multiple detected
  codes ask you to select one area; unreadable images offer crop/retry guidance.
- Read light-on-dark QR codes, including white codes on dark posters. Both
  file selection and clipboard input use the same decoding and safety checks.
- Text QR results have a read-only view and an explicit copy action.
- Updated desktop cryptography and web dependencies, with checks preventing
  the reported development-tool dependency chain from entering runtime bundles.

## Install or update

1. Download the Windows x64 ZIP and `SHA256SUMS.txt` below.
2. Exit QR Scanner from its tray menu, then extract the entire ZIP.
3. Open `QR-Scanner.exe`; choose **Create QR** to try the new feature.
4. Refresh [qrwebcam.vercel.app](https://qrwebcam.vercel.app/) on your phone.

Pairings are retained in the same Windows account and phone browser. Normal
use requires no Python installation, PowerShell setup or Vercel login.

## Verification and limits

285 desktop tests and 100 PWA tests passed, along with the production build and
lint. The user confirmed that a created QR scans on a phone, and that selecting
the supplied poster and pasting another QR both work on the live phone site.
See the [verification record](https://github.com/alpkonakci/webcam-qr-scanner/blob/v0.2.0-beta.5/docs/v0.2.0-beta.5-verification-2026-10-11.md)
for packaged-EXE checks and scope.

The EXE is unsigned and may trigger SmartScreen. Low-detail images may remain
unreadable; resizing cannot restore missing pixels. Clipboard support depends
on the phone browser. Production npm audit has zero reported vulnerabilities;
eight high-severity development-tool package warnings remain open. Full device
coverage and independent protocol/security review remain pending before stable.

## Türkçe

**Create QR** ile bağlantı veya kısa metinden çevrimdışı QR oluşturun; **Save PNG**
ile kaydedin veya **Copy QR** ile kopyalayın. Video/GIF/PDF için paylaşım bağlantısını
kullanın. Telefonda **Read from image → Choose image / Paste image** ile görseli
seçin ya da yapıştırın; tek QR otomatik okunur, birden fazla QR algılanırsa alan
seçilir. Koyu zemindeki beyaz QR'lar da desteklenir.

Eski uygulamayı tepsiden kapatın, ZIP'i tamamen çıkarıp yeni `QR-Scanner.exe`'yi
açın ve telefondaki sayfayı yenileyin. Aynı hesap/tarayıcıdaki eşleşmeler korunur.
Bu bir beta yayınıdır; önceki sürümler GitHub'da kalır.
