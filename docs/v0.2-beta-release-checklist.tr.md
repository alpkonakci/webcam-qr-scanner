# v0.2.0-beta.1 yayın kontrol listesi

[English](v0.2-beta-release-checklist.md)

Bu liste Telefon-PC betasının yayın kapısıdır. Kaynak kod testinin geçmesi,
gerçek cihaz veya dağıtım testinin yerine geçmez.

## Güncel karar

- Hedef: GitHub'da **pre-release** olarak `v0.2.0-beta.1`.
- Kararlı sürüm: önerilen sürüm `v0.1.1` olarak kalır.
- Durum: aşağıdaki Vercel önizleme ve gerçek cihaz bölümleri geçmeden
  **yayıma hazır değil**.
- Mevcut Sites/Cloudflare yayını, yeni production origin doğrulandıktan sonra
  en az 48 saat daha açık kalır.

## Otomatik kapılar

- [ ] Tüm Python masaüstü testleri geçiyor.
- [ ] Paketlenmiş EXE `--self-test` kontrolünü geçiyor.
- [ ] PWA build, typecheck, lint ve tüm PWA testleri geçiyor.
- [ ] İptal testleri önce relay iptali, sonra yerel silme ve ağ hatasında
  fail-closed saklama davranışını kanıtlıyor.
- [ ] İptal edilmiş PWA eşleşmesi yalnızca tam `pair_revoked` hatasından sonra
  siliniyor.
- [ ] Secret taraması; izlenen dosyalarda veya üretilen tarayıcı paketinde URL
  içeriği, token, anahtar, Authorization başlığı veya gerçek sır bulmuyor.

## Vercel önizleme kapıları

- [ ] Vercel GitHub dalına bağlandı ve Root Directory `pwa` seçildi.
- [ ] `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY` ve
  `RELAY_RATE_LIMIT_PEPPER` yalnızca Vercel ortamında tanımlandı; Git'e girmedi.
- [ ] `/healthz` beklenen, veri içermeyen yanıtı veriyor.
- [ ] Anonim Supabase cihaz oturumu e-posta, telefon veya hesap ekranı olmadan
  açılıyor.
- [ ] Özel Realtime cihaz kanalı bağlanıyor.
- [ ] Zorla kesilen Realtime, beş saniyelik sorguyla teslimata devam ediyor.
- [ ] Sağlıklı Realtime bağlantısında yalnızca 60 saniyelik güvenlik eşitlemesi
  çalışıyor.
- [ ] API hataları istek gövdesi veya sır sızdırmadan kararlı hata kodu veriyor.

## Gerçek cihaz matrisi

Her maddeyi bir kez iPhone Safari ve bir kez Android Chrome ile uygulayın.

- [ ] E-posta, telefon veya mağaza uygulaması olmadan eşleştirme.
- [ ] Mobil veri üzerinden başka ağdaki PC'ye gönderim.
- [ ] PC'de alan adı ve tam URL'yi gösterme; yalnız PC onayından sonra açma.
- [ ] HTTP uyarısı gösterme ve HTTP(S) dışındaki şemaları reddetme.
- [ ] Tarayıcı, masaüstü uygulaması ve PC yeniden başladıktan sonra eşleşmenin
  devam etmesi.
- [ ] Hem Realtime hem zorlanmış kurtarma sorgusu üzerinden teslim.
- [ ] PC çevrimdışıyken relay'de yeni mesaj saklamama.
- [ ] Windows'tan erişimi kaldırma; eski telefonun `pair_revoked` alması,
  IndexedDB eşleşmesini silmesi ve yeniden eşleştirme seçeneği göstermesi.

Cihaz modeli, işletim sistemi/tarayıcı sürümü, ağ türü, production adresi, test
zamanı ve sonucu Pull Request'e yazın. Özel QR kod veya URL eklemeyin.

## Gizlilik ve işletim incelemesi

- [ ] Vercel function loglarında URL, Authorization başlığı, token, anahtar, QR
  görüntüsü veya ciphertext gövdesi yok.
- [ ] Supabase loglarında URL, Authorization başlığı, token, anahtar, QR
  görüntüsü veya ciphertext gövdesi yok.
- [ ] Tablolarda yalnız belgelenmiş token özetleri, opaque yönlendirme verisi,
  kısa ömürlü şifreli zarflar ve işletim zamanları bulunuyor.
- [ ] Açık PWA paketinde yalnız publishable key var; Supabase secret key veya
  rate-limit pepper yok.
- [ ] Üçüncü taraf bildirimleri gerçek Windows ve PWA bağımlılık sürümleriyle
  eşleşiyor.

## Paketleme ve yayın

- [ ] ZIP temiz Windows kullanıcı hesabında veya temiz bilgisayarda çalışıyor.
- [ ] `SHA256SUMS.txt`, indirilebilir ZIP ile doğrulanıyor.
- [ ] Draft PR açıldı ve otomatik/manuel test kanıtları eklendi.
- [ ] Yalnız gerekli kontroller geçtikten sonra `main` ile birleştirildi.
- [ ] `v0.2.0-beta.1`, ZIP, checksum ve sürüm notlarıyla GitHub pre-release
  olarak yayımlandı; en güncel kararlı sürüm yapılmadı.
- [ ] İki barındırma sistemi en az 48 saat birlikte açık kaldı.
- [ ] Eski yayın ve kullanılmayan bulut kaynakları yalnız ayrı, açık onaydan
  sonra kaldırıldı.

Beta, kararlı `v0.2.0` sürümüne yükseltilmeden önce bağımsız protokol ve
kriptografi incelemesi zorunludur.
