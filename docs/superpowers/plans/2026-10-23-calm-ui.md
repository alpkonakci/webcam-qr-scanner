# Calm UI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for parent web work;
> the user-requested UI Designer owns the independent desktop task.

**Goal:** Apply the approved minimal refinement without changing security flows.
**Architecture:** Keep existing React views and Win32 controls; change composition,
style and native QR presentation. Reuse the existing connection/delivery domains.
**Tech Stack:** Next/React, CSS, Python/Win32.
**Spec:** `docs/superpowers/specs/2026-10-23-calm-ui-design.md`.

## Global Constraints

No new dependencies, no protocol changes, no deployment. Preserve TR/EN,
saved-pair versus reachability versus verified receipt distinctions. Preserve
delivery locks and QR secret privacy; native Windows controls remain accessible.

## Review Focus

- Paired mobile primary action must retain pending/unconfirmed/delivered locks.
- Unpaired/desktop result still opens locally and never sends automatically.
- Help consolidation must preserve recovery/storage/privacy instructions.
- Long Turkish text and keyboard focus must remain visible.
- QR close/cancel, expiry and phone-return events retain existing precedence.
