# v0.2.0-beta.1 — limited beta

**Limited beta / pre-release.** The user authorized publication with the
remaining acceptance gaps disclosed on 2026-10-03. This is not a claim that
every release gate has passed. The recommended stable release remains v0.1.1.

## What's new

- Phone-to-PC QR scanning through the public `qrwebcam.vercel.app` service,
  with encrypted delivery and PC approval before opening a received link.
- Saved phone pairings, access removal and re-pairing, plus improved handling
  of expired/revoked browser records and pairing-page return navigation.
- A home screen for camera scanning, selected screen-area scanning and phones.
- Monitor selection for multi-display screen capture and drag-to-select QR area.
- Branded Windows icon, compact control windows and a close-to-tray/exit choice.
- Improved tray shutdown and retained home/taskbar window during link approval.
- Supabase private Realtime wake-ups with authenticated recovery polling.

## Installation

Download the Windows x64 ZIP and `SHA256SUMS.txt`, verify the ZIP hash, extract
the entire folder, then run `QR-Scanner.exe`. Keep the license files with it.
The public production service does not require a Vercel bypass secret or a
PowerShell setup for normal use. Old preview-only launcher settings are not
needed for this production package.

## Known limitations

- Clean Windows account/machine acceptance has not been completed. The package
  was tested in the existing Windows account, including its packaged self-test.
- iPhone full testing and the Android pair/send/remove/re-pair/exit flow were
  user-confirmed. Android mobile-data/different-network, restart, scheme-policy,
  and offline-receiver acceptance checks are not fully recorded.
- Deployed forced Realtime interruption/fallback delivery and healthy-channel
  timing evidence remain incomplete. Recent cloud logs were sampled, not
  exhaustively audited; Auth/error-path and live table-content review remain
  open. Do not treat this beta as a privacy/security certification.
- Protected/DRM video, including some Prime Video playback, can appear black
  in screen capture. Use the phone/camera or an unprotected QR display instead.
- Some Android camera apps do not recognize the pairing QR automatically;
  Google Lens is an alternative. Keep the pairing window open and scan a fresh
  code before it expires.
- Browser private mode or cleared site storage loses the saved phone pairing.
- This is beta software, not an independently audited stable protocol release.
  The remaining acceptance gates are recorded in
  [the verification report](https://github.com/alpkonakci/webcam-qr-scanner/blob/v0.2.0-beta.1/docs/v0.2-beta-verification-2026-09-30.md).
