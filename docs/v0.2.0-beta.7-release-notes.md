# Webcam QR Scanner v0.2.0-beta.7

## Fixed

- **Open scanner on phone** now closes its desktop QR window automatically
  after the phone homepage acknowledges opening. Previously this reusable QR
  was only a public homepage address, with no return signal to the PC.
- The temporary acknowledgement expires after two minutes, is kept in the
  URL fragment rather than the request URL, and is removed from the address
  bar on opening. It carries no pairing secret, root key, sender or receiver
  credential. It cannot establish or replace a pairing. Existing browser
  credentials remain necessary for Send to PC.
- Back, Escape and expiry close the QR and clean up the temporary relay
  session. If session creation is unavailable, a public homepage QR and a
  clear manual-close explanation remain available.

## Distribution

MIT is unchanged: there is no activation key or user license verification.
The Windows ZIP now includes immutable application source, pinned pystray and
certifi source archives, full dependency notices and `REBUILDING.md`.
The unnecessary FFmpeg DLL is excluded; local camera and image support remain.
Modified-library rebuilding was verified during the distribution review.
The phone website includes complete browser dependency license notices.

## Update

Exit the old QR Scanner, extract the entire Windows x64 ZIP and run
`QR-Scanner.exe`. Refresh https://qrwebcam.vercel.app on your phone.
Pairings remain saved in the same Windows account and phone browser.

This remains a pre-release, not a stable release. The EXE is unsigned.
Automated checks do not replace real-device acceptance or independent review.
