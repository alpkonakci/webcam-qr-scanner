# Webcam QR Scanner v0.2.0-beta.6

Development dependency security maintenance. QR creation, image reading and
Phone-to-PC features from beta.5 are retained.

## Fixed

The eight high-severity npm package warnings shared one root advisory,
[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm), in
`braces`. There is still no official patched braces release. This project
replaces the two build-tool fast-glob call sites with a private, bounded
adapter using tinyglobby 0.2.17. The old micromatch/braces code is removed from
the installed dependency graph; no advisory is ignored or package version
faked. Both the complete npm audit and production-only audit report **0**.

The cleared package warnings were braces, micromatch, fast-glob,
@next/eslint-plugin-next, eslint-config-next, vite-plugin-dynamic-import,
vite-plugin-commonjs and vinext. Next lint rules and the alternate Vite/Worker
build are retained. Consumer upgrades require rechecking the adapter's supported
API and compatibility tests.

## Verification

Clean locked installation, real Next/Vite consumer compatibility, deeply nested
pattern rejection, production builds, type checking, lint, 105 PWA tests and
285 desktop tests. Windows ZIP checksums are supplied below. Details:
[verification record](https://github.com/alpkonakci/webcam-qr-scanner/blob/v0.2.0-beta.6/docs/v0.2.0-beta.6-verification-2026-10-11.md).

## Update

Exit the old QR Scanner, extract the entire Windows x64 ZIP and run
`QR-Scanner.exe`. Refresh https://qrwebcam.vercel.app on the phone. Pairings
remain saved in the same Windows account and phone browser.

This is a pre-release; the EXE remains unsigned. Zero reported audit findings
does not replace device acceptance testing or independent protocol review.
ESLint 9 and esbuild-kit deprecation notices are separate maintenance items,
not the eight vulnerability findings fixed here.
